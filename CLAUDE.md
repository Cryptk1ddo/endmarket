# CLAUDE.md

## PROJECT IDENTITY

Project codename: HYDRA

HYDRA is a luxury brutalist waterware and architectural objects brand.

This project is NOT:

* a startup SaaS,
* a generic ecommerce store,
* a Shopify-template brand,
* or a mass-market plumbing company.

HYDRA exists at the intersection of:

* architecture,
* industrial design,
* brutalism,
* editorial fashion culture,
* and conceptual luxury.

The website should feel like:
"a luxury architectural object disguised as an ecommerce experience."

Everything must feel:

* engineered,
* restrained,
* intelligent,
* cinematic,
* severe,
* and expensive.

Performance is luxury.

Requirements:

* server-first rendering
* aggressive lazy loading
* image optimization
* GPU-safe animations

Prioritize:

1. visual stability
2. smooth interaction
3. low bundle size
4. clean architecture
