## How to Download & Organize

1. **For each model**, visit its Ozon product page
2. **Gallery section** — right-click each image
3. **"Save image as..."** → save to this directory with exact naming
4. **Image 1**: Product front view (main image)
5. **Image 2**: Detail/side view
6. **Image 3**: Remote control or lifestyle shot
7. **Image 4**: Installation/room context shot

## Image Specs

- **Format**: JPG or PNG
- **Size**: 600px × 600px minimum (responsive)
- **Quality**: Maximum clarity (compress after if needed)

## Ballu

Ballu images are served **directly from ballu.ru** URLs in code — no local files needed.
